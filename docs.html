API Gateway - Documentation

Authentication

All requests must include a valid API key in the X-API-Key HTTP header.

Endpoints

GET /api/users

Returns a list of users.

Sample Response:
[
    {"id": 1, "name": "Alice"},
    {"id": 2, "name": "Bob"}
]

GET /api/products

Returns a list of products.

Sample Response:
[
    {"sku": "A123", "productName": "Widget"},
    {"sku": "B456", "productName": "Gadget"}
]

Error Responses

  • 401 Unauthorized - Missing or invalid API Key
  • 429 Too Many Requests - Rate limit exceeded (10 requests per minute)
  • 404 Not Found - Invalid API path
